# Workflow and safety boundaries

| Stage | SGE role | Human boundary |
|---|---|---|
| Discovery | Organize prompts and signal sources | Verify source relevance |
| Monitoring | Retrieve supported signals | Respect source policies and limitations |
| Evidence | Store/review source context | Decide what is credible |
| Opportunity | Heuristic evaluation | Treat score as advisory |
| Match | Connect problem and product context | Review assumptions |
| Reply | Draft response | Human edits and sends externally |
| Conversation | Record stages and consent | Respect refusal and privacy |
| Lead/outcome | Record user-entered events | No independent verification |
| Finance | Aggregate recorded costs/outcomes by currency | Confirm source records |
| Next step | Deterministic guidance | User chooses and executes |
