Live Public Signal Discovery

This experimental connector reads public Hacker News API story lists and items directly from Firebase. It is a limited live source test—not global discovery. Search is keyword filtering over recent Ask HN / Show HN / New story candidates, not full-text platform search.

Boundaries: Read-only requests. No login, posting, comments, messaging or account access. Results can be incomplete, irrelevant or stale. Use source links to inspect the original context. Respect API availability; this tool makes modest requests and stops on errors.

Run discovery

Lower limits reduce API calls and load. This connector filters story title/text only; comments are not collected.

Results

How this pilot works

  1. Fetch public Ask / Show / New story ID lists.
  2. Fetch a bounded number of story records, in parallel with a small cap.
  3. Match user-specified terms against title and text.
  4. Rank by matches and recency proxy (ID order).
  5. Inspect original thread and record evidence in the Engagement Center.

Next source candidates require separate connector implementations, credentials where required, policy reviews and tests. This does not claim to search other platforms.
