Site Intelligence & Internal Link Graph

A source-informed internal-link audit workspace. The current sitemap inventory is preloaded, but outgoing links are not live-crawled. Add each page's observed outgoing internal links, or import CSV, to analyze reachability and orphan risk. Results are calculated locally.

Scope & evidence

Inventory: Sitemap-derived list loaded from source at implementation time. Edges: user-entered or imported links—not verified crawl data. Orphan detection: heuristic based on the graph you provide, excluding homepage and pages marked as seeds.

Import graph CSV

CSV columns: page,links. Use comma-separated link targets within links, quoted fields if needed. The target names should match page filenames.

Page inventory & observed links

Use filenames, or URL paths, for link targets. Use semicolon-separated outgoing targets. Mark seeds if they are entry pages that intentionally receive external traffic or are directly navigable.

Journey cluster suggestions (heuristic)

  • Problem pages should link to relevant guides, comparisons, tools and product pages where the link helps the reader.
  • Free tools should provide an optional, relevant next step—not a forced product link.
  • Comparisons should link to both the product pages and underlying criteria or guides.
  • Portfolio/product pages should link back to relevant problem-solving pages, FAQs and installation/support content.
  • Distribution/SEO workspaces should be discoverable from navigation, while avoiding a dense sitewide link network.
