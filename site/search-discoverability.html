Technical audit checklist

  • Confirm HTTPS and page response status; check redirects and canonical targets.
  • Review robots.txt and sitemap.xml for valid paths, no unintended exclusions and sitemap freshness.
  • Check title, meta description, heading structure, canonical and internal links page by page.
  • Confirm pages are useful, unique and not thin/duplicative; update or consolidate overlapping pages.
  • Verify accessible HTML content, responsive design, page speed, image alt text and keyboard navigation.
  • Inspect indexing and performance in Search Console when the owner connects the property.
  • Submit sitemap to Search Console and Bing Webmaster Tools after verifying property ownership; submission is not indexing guarantee.
  • Track search queries, landing pages, CTR, impressions and clicks over comparable periods; treat data as observed, not inferred.

Content and internal linking strategy

  • Build topic clusters around distinct audience problems, products, use cases and buying decisions.
  • Link problem-solving pages to relevant product pages and free tools; link guides to related guides without forced links.
  • Each page should answer the intended question directly, show steps or evidence, state limitations and offer a useful next action.
  • Use consistent product names, verified features, prices and product status across pages.
  • Update comparison pages only when claims and competitor details are reviewed; label date and scope where appropriate.
  • Use FAQ headings only for genuine user questions; structured data does not guarantee rich results.

Structured data

Use appropriate, truthful structured data (such as WebSite, WebPage, BreadcrumbList and SoftwareApplication where relevant). Ensure structured data matches visible content. Avoid unsupported review ratings, fabricated offers, organization details or customer claims.

Search and GEO

For both traditional search and AI-assisted discovery, focus on sourceable facts, clear definitions, original useful evidence, stable entity/product names, crawlable pages, helpful structure and transparent limitations. Measure visibility only where reliable data is available; do not promise AI citations.

Internal site search

Open the website search. Its local index is a curated static catalog of pages and keyword descriptions. It is not a server search and currently requires index maintenance when new content is added.

Search engine management tools

  • Google Search Console — query/page data, indexing diagnostics and sitemap submission (owner access needed).
  • Bing Webmaster Tools — crawl/index diagnostics and search performance (owner access needed).

No search console property, analytics account, backlink provider or external crawler was connected in this work batch. Technical recommendations are not represented as account-level changes.
